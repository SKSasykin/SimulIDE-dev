# Редактор SPIFFS для ESP

Компоненты ESP32, ESP32-S3, ESP32-C3 и ESP8266 имеют действие `Open SPIFFS...`
в контекстном меню. Оно открывает редактор файлов SPIFFS во flash-образе.

Редактор предоставляет режимы Text и Hex. Распространённые текстовые и исходные
расширения (`txt`, `csv`, `json`, `xml`, `html`, `c`, `py` и другие) по умолчанию
открываются в режиме Text, остальные — в режиме Hex. Оба режима доступны для
редактирования при наличии доступной для записи рабочей копии.

Редактор позволяет создавать пустые текстовые и бинарные файлы, импортировать
файлы с компьютера, экспортировать выбранные файлы на компьютер и удалять файлы.
Также отображаются занятое, свободное и общее место SPIFFS.

Изменения сохраняются в рабочей копии и не изменяют исходный файл прошивки.
Образы без обнаруженного раздела SPIFFS остаются доступными только для чтения.
